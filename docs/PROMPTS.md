# Prompts pendientes para Gemini

Listos para copiar y pegar, uno por bloque. Cuando una imagen ya está en el juego, el prompt pasa a `docs/PROMPTS-ARCHIVO.md`, sin borrarlo.
Todos piden **fondo blanco liso**: se recorta mejor que el cuadriculado "transparente" que a veces dibuja Gemini.

**Para descargar:** abrí la imagen en Gemini y usá **"Descargar en tamaño original"**.

**Para que salgan parejas:** cada grupo en **su propia conversación de Gemini**. Con la primera que te guste, pedile: "usá esta imagen como referencia de estilo para todas las que siguen". Si una sale distinta, descartala y pedila de nuevo.
